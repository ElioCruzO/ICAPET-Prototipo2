# **App Name**: Contact Keeper

## Core Features:

- Add Contact: Add a new contact with fields for name, phone number, email, and location.
- View Contacts: View a list of all contacts, with options to sort and filter.
- Edit Contact: Edit existing contact information.
- Delete Contact: Delete a contact from the directory.
- Record Interaction: Record each interaction with a contact, including date, and notes on the purpose.
- Summarize Interactions: Generate summaries of interaction histories using an LLM, acting as a tool, highlighting key discussion points and agreed-upon actions.

## Style Guidelines:

- Primary color: Slate blue (#778899) for a professional, calming feel.
- Background color: Light gray (#F0F8FF), nearly white, for a clean and uncluttered look.
- Accent color: Teal (#008080) to draw attention to important action items or data.
- Body and headline font: 'Inter' (sans-serif) for a modern, readable style.
- Simple, minimalist icons to represent common actions and categories.
- Clean, card-based layout to display contact information clearly.
- Subtle transitions and animations for a smooth user experience.
